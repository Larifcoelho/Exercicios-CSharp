Exercícios em C#
------
*Sobre o repositório*

Este repositório reúne exercícios desenvolvidos em C# com o objetivo de praticar e aprimorar conhecimentos em programação e lógica computacional.

Os exercícios são realizados durante o processo de aprendizado, abordando conceitos fundamentais da linguagem e explorando diferentes formas de resolver problemas por meio do código.

*Conteúdos abordados*

Variáveis e tipos de dados
, operadores aritméticos e lógicos
, estruturas condicionais (if, else, switch)
, estruturas de repetição (for, while, do-while)
, arrays e listas
, métodos e funções
, manipulação de strings
, programação Orientada a Objetos (POO)
, tratamento de exceções
, tecnologias utilizadas
, linguagem: C#
, plataforma: .NET
, IDE: Visual Studio / Visual Studio Code
e organização.

Os exercícios estão organizados em diretórios e arquivos separados, facilitando a identificação dos conteúdos e o acompanhamento da evolução dos estudos.

*Objetivo*

Este projeto tem como finalidade consolidar os fundamentos da linguagem C#, desenvolver o raciocínio lógico e construir uma base sólida para projetos futuros.

O repositório será atualizado conforme novos exercícios e conteúdos forem desenvolvidos.
